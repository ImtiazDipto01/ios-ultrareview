# Public evaluation records

- [Development summary](development-summary.json): sanitized derived 1.0.0 outcomes, with original report digest and runtime distinctions.
- [Provenance recovery](provenance-recovery.json): post-hoc selected host model/settings and whole-session usage for nine reviewers, including historical aided passes.

See [method and limits](../../docs/evaluation.md). These files are not original freeze records or private raw evidence. The original local archives remain unchanged and are not redistributed because they include private host/session details. Digests retain audit identity but cannot independently verify sources that are not public.

Ordinary PR reviewers should not load this directory. New independent discovery runs must freeze predictions before evaluator access.
